# Lar marks

The sources for every icon the apps ship. `scripts/brand-icons.sh` writes the PNG, ICO, and
favicon files from them; rerun it after a change here and commit what it writes.

| File               | Mark                                                              |
| ------------------ | ----------------------------------------------------------------- |
| `lar.svg`          | The logo, Bone: the main mark, on a dark ground                   |
| `lar-flat.svg`     | The logo, Flat: small sizes, favicons, and one-colour use on dark |
| `lar-flat-ink.svg` | The logo, Flat on a light ground                                  |
| `lar-movies.svg`   | The Lar Movies app icon                                           |
| `lar-music.svg`    | The Lar Music app icon                                            |

At 32 and 16 pixels the logo is always Flat.

The pictures in the app icons are Lucide's `play` and `music` icons
([ISC](https://github.com/lucide-icons/lucide/blob/main/LICENSE), © Lucide Contributors).
