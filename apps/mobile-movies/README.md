# [movies] for iPhone

The iOS app: Expo SDK 58, Expo Router, and Uniwind (Tailwind 4 for React Native) over the platform
SDK (`@media/sdk/react`) and `@media/mobile-core`. Screens follow the Paper pages **14–20 iOS** in the `[movies]` file; tokens in
`src/global.css` keep their Paper names, and dark is the default theme.

## How it connects

People type the server's address. The app checks `/api/health`, reads the core's Convex URL and the
movies web client's address from `/api/client-config`, and opens the platform client on the core.
Every sign-in goes through the server's sign-in boundary. Connection Details takes both addresses
for servers that do not share their Convex URL.

People sign in with a username and password, or with a code another signed-in device approves. A
password sign-in also keeps the phone's device grant in the shared keychain, so the phone's other
[media] apps sign in without asking; each app keeps its own session and shows as its own device.
Switching person is signing out, then signing in. [ADR 0020](../../docs/decisions/0020-branded-clients-with-one-sign-in.md), "The movies iOS app as
built", lists what each keychain holds and when the app asks for the password again.

Invites open from a pasted account client link (`<server>/invite#<code>`) on Open an Invite, or
from the app's own link `movies://invite?server=<server>&code=<code>`, which connects to that
server first. A shared title opens the movies web client at `<server>/movies/title/<id>`.

The owner screens (libraries, users, import, backups) still use the old movies SDK until they move
onto the core, so against an install they fail to load.

## Tabs

The tab bar has Home and Downloads, with Search as the system search tab in its own circle
(Paper C01). Home holds everything to browse: the hero, Continue Watching, Recently Added, My
List, and Collections. Genres, collections and people open from there or from Search, and the full
My List opens from You. Selecting Search moves the tab bar's search field above the keyboard
(E00), and scrolling down minimizes the bar to a Home circle and the Search circle (C02).

## Downloads

Movies and episodes download to the iPhone from their `…` sheets and play offline in the same
player. The core keeps the list of what this device holds and says when an item expired; the files
live under the app's documents folder, per server and person, and the media service prepares an MP4
when the original does not play on the iPhone within Download Settings' quality. When the server cannot be reached at launch, Go to Downloads opens what is kept.

## Develop

Native code needs a development build; Expo Go does not carry the modules this app uses. On a Mac
with Xcode:

```sh
pnpm install
cd apps/mobile-movies
npx expo run:ios            # builds the dev client into a simulator and starts Metro
```

After the first build, only JavaScript changes reload: `pnpm --filter @media/mobile-movies dev` starts Metro, and
the dev client opens it from `exp+movies://expo-development-client/?url=<metro-url>`. Rebuild
when a dependency with native code changes.

From another machine, sync the repo to the Mac, build there, and reverse-forward the ports the
simulator needs (Metro, Convex, and the media service) so `127.0.0.1` URLs work unchanged:

```sh
ssh -N -R 8081:[::1]:8081 -R 3210:127.0.0.1:3210 -R 8080:127.0.0.1:8080 mac
```

`ios/` is generated by `expo prebuild` and is not committed. Configure native behavior in
`app.json` and config plugins.

## Layout

| Path                       | Role                                                                 |
| -------------------------- | -------------------------------------------------------------------- |
| `src/app`                  | Expo Router screens, grouped by session phase in `_layout.tsx`       |
| `src/components/ui`        | Text, buttons, fields, rows, and headers from Paper's iOS components |
| `src/components`           | Posters, cards, and avatars                                          |
| `src/components/browse`    | Home's hero, rails, grids, and context menus, and the tabs' chrome   |
| `src/components/downloads` | Downloads: rows, the list, the engine's hooks, and offline playback  |
| `src/components/owner`     | Owner Settings: the library form, import state, and shared parts     |
| `src/session`              | Connection, platform provider, sign-in, and the session phase        |
| `src/lib`                  | Catalog types, routes, artwork URLs, formatting, and failures        |

The root stack shows only the screens of the current phase (not connected, signed out, ready), so
signing in or out moves to the right screen without explicit navigation. A server without an owner adds two: creating the owner account, and
setting up its first library.

## Checks

`pnpm typecheck`, `pnpm lint`, `pnpm fmt:check`, `pnpm test`, and `pnpm knip` cover this app like
the rest of the repo. Tests run in Node, so test pure modules (`src/lib`) and keep React Native
imports out of them.
