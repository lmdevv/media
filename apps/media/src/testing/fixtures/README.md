# Test fixtures

Small binary files the tests use as they are; everything else is generated by `fixture-library.ts`.

- `vobsub.mkv` (3.6 KB): one DVD (VobSub, `dvd_subtitle`) subtitle track on a 720x576 canvas and
  no other stream; two subtitles, "Burned in from VobSub." at 0–3 s and "Second picture subtitle."
  at 4–6.5 s. ffmpeg cannot encode bitmap subtitles from text, so it was made with spumux
  (dvdauthor), whose font (`DejaVuSans.ttf`) must be in `~/.spumux/`:

  ```sh
  ffmpeg -f lavfi -i color=c=black:s=720x576:r=25 -t 8 -target pal-dvd -an base.mpg
  spumux -s0 sp.xml < base.mpg > subs.mpg   # sp.xml: <subpictures format="PAL"><stream><textsub
                                            # filename="t.srt" font="DejaVuSans.ttf" fontsize="28.0"
                                            # movie-width="720" movie-height="576" .../></stream></subpictures>
  ffmpeg -i subs.mpg -map 0:s:0 -c:s copy vobsub.mkv
  ```

- `libx265-ffmpeg-7.1-init.mp4` (3.9 KB) and `libsvtav1-ffmpeg-7.1-init.mp4` (1.3 KB): the
  `init.mp4` of a software HEVC and a software AV1 HLS run of the service's, written by the Docker
  image's Debian ffmpeg 7.1.5 (libx265 4.1, SVT-AV1 2.3.0) from 20 s of the demo library's
  Feature Test at 1688x720 with copied AAC. Each holds the empty `sdtp` box that ffmpeg 7.1 writes
  for an encoder that marks pictures disposable, which AVFoundation refuses. Made with the
  service's `hlsCommand` arguments for a client that plays only that codec.

`covers/` holds one small cover of each kind the music art route must serve unchanged in look,
made with ImageMagick 7.1, exiftool 13, ffmpeg, and colord's ICC profiles (`$ICC`):

- `transparent.png` (RGBA) and `palette.png` (palette with `tRNS`): a lime disc, opaque, on
  magenta that is fully transparent. `alpha.webp` is the same picture as lossless WebP with alpha.

  ```sh
  magick -size 320x320 xc:lime \( -size 320x320 xc:black -fill white -draw "circle 160,160 160,12" \) \
    -alpha off -compose CopyOpacity -composite -background magenta -alpha background -strip \
    -define png:exclude-chunks=date,time PNG32:transparent.png
  magick transparent.png -strip -colors 16 PNG8:palette.png
  magick transparent.png -strip -define webp:lossless=true -define webp:exact=true alpha.webp
  ```

- `profiled.jpg`: a navy-to-orange gradient carrying `SwappedRedAndGreen.icc`, so a copy that
  dropped the profile would show red and green swapped.
  `magick -size 320x320 gradient:navy-orange -strip -quality 80 -profile $ICC/SwappedRedAndGreen.icc profiled.jpg`
- `rotated.jpg`: a 320x240 picture with a red top-left corner, stored rotated to 240x320 with EXIF
  orientation 6. `magick -size 320x240 gradient:white-gray40 -fill red -draw "rectangle 0,0 79,59"
  -strip -rotate -90 -quality 80 rotated.jpg && exiftool -all= -Orientation=6 -n rotated.jpg`
- `cmyk.jpg`: the gradient as a CMYK JPEG. `magick ... -colorspace CMYK -quality 80 cmyk.jpg`
- `gamma.png`: the gradient with only a `gAMA` chunk (gamma 0.5), no `sRGB` or `iCCP`.
  `magick ... -define png:include-chunk=gAMA -define png:exclude-chunks=sRGB,iCCP,date,time,bKGD,cHRM -set gamma 0.5 PNG24:gamma.png`
- `animated.gif`, `animated.webp`: two 160x160 frames, navy then orange.
  `magick -delay 20 \( -size 160x160 xc:navy \) \( -size 160x160 xc:orange \) -loop 0 animated.gif`
- `animated.png`: an APNG of two navy frames.
  `ffmpeg -f lavfi -i "color=c=navy:s=160x160:r=5,format=rgb24" -t 0.4 -plays 0 -f apng animated.png`
